## Fluxo de Trabalho

O projeto segue **Git Flow** e boas práticas de versionamento:
- **Branches principais:**  
  - `main`: branch de produção.
  - `develop`: branch de desenvolvimento.
- **Branches secundárias:**  
  - `feature/*`: novas funcionalidades.
  - `bugfix/*` e `fix/*`: correções de bugs.
  - `hotfix/*`: correções urgentes em produção.
- **Exemplo de branches ativas:**  
  - `main`, `develop`, `feature/frontend`, `feature/o-começo`, `fix/ajusts`, `fixes`, `natorjunior-patch-1`.

**Commits** são pequenos, frequentes e descritivos, utilizando um padrão de emojis para indicar o tipo de alteração (✨ nova feature, 🐛 bugfix, 📝 docs, etc).

**Pull Requests**:
- Devem ser abertos para qualquer alteração relevante, seguindo padrão de título e descrição detalhada.
- Proibido commitar diretamente nas branches `main` ou `develop`.
